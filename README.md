# PONG — Classic Arcade Clone

A single-file Pong clone in vanilla JS + canvas, single player vs AI, rendered inside a 3-stripe arcade cabinet bezel with a CRT glass shader (barrel distortion, scanlines, reflections).

## Play

- Open [index.html](index.html) — that's the whole game (no build step, no dependencies).
- Up/Down or W/S: move · P: pause · M: mute · C: cycle CRT glass mode · Any key: start
